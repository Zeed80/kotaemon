# Document Types

Типы документов позволяют классифицировать файлы при индексации и извлекать структурированные данные (номера счетов, контрактов и т.п.) для улучшения RAG и построения связей между документами.

## Базовые типы

По умолчанию доступны типы:

- **invoice** — счета
- **letter** — письма
- **drawing** — чертежи
- **tech_spec** — технические спецификации
- **sketch** — эскизы

## Пользовательские типы

В **Resources → Document Types** можно:

1. **Добавить тип** — задать отображаемое имя, slug, ключевые слова (для классификации), схему полей (JSON), шаблон промпта для экстракции.
2. **Редактировать / удалить** — выбрать тип в таблице и изменить или удалить.
3. **Сгенерировать промпт (LLM)** — по схеме полей LLM формирует шаблон промпта.
4. **Переиндексировать по типу** — переиндексировать файлы выбранного типа в указанной коллекции.

### Схема полей (schema_def)

Список объектов вида:

```json
[
  {"name": "invoice_number", "type": "str", "description": "Номер счета"},
  {"name": "amount", "type": "float", "description": "Сумма"},
  {"name": "contract_number", "type": "str", "description": "Номер контракта"}
]
```

Поддерживаемые типы: `str`, `int`, `float`, `bool`, `list`, `dict`.

## Индексация

- В настройках пайплайна (**Settings** или при загрузке) можно задать **Тип документа**:
  - **Автоматический** — классификатор определяет тип по ключевым словам.
  - Конкретный тип — все файлы обрабатываются с выбранным типом.
- При индексации извлекаются структурированные данные и строятся **связи между документами** (document_links), например: счёт → ссылка на контракт по `contract_number`.

## document_links и LightRAG

Связи сохраняются в `Source.note["document_links"]` и при использовании **LightRAG** автоматически добавляются в граф как рёбра между сущностями (документ ↔ референс). Это улучшает поиск и рассуждения по связанным документам.

## Таблица document_type

Пользовательские типы хранятся в таблице `document_type` (Alembic-миграция или автоматическое создание при `KH_ENABLE_ALEMBIC=false`).
